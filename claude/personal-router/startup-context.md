When the conditions below apply, invoke `pstack:poteto-mode`. Its registration must be verified before activation.

Load the personal router when the task meets any of these conditions:

- It needs coordinated changes across files. One change requires another to work correctly.
- It changes how other code calls a function.
- It needs a meaningful design decision.
- It concerns a bug with an unknown cause or a performance problem.
- It has several dependent stages that need a playbook.

Handle simple questions and obvious contained edits directly. Handle obvious mechanical edits across files directly, such as unrelated typo fixes.

Load the router if investigation later reveals one of these conditions.

When the user requests a specific skill, enter that skill directly.

Follow the user's instructions and the task's authorization.
