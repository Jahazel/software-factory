# Investigation

1. Run `worktree` before repository edits.
2. Choose only the needed route: `how` for code behavior, `git log` and `git blame` for earlier decisions, and official sources for outside questions. Reuse current findings. Use `research` only when saved findings are wanted; it requires a Markdown findings file.
3. Answer in chat by default. Cite sources, separate facts from assumptions, and name uncertainties.
4. For comparisons, show a tradeoffs table and recommend an option with reasons.
5. For "are we sure?" questions, check the claim against evidence. Push back when the evidence contradicts the premise.
6. Apply `unslop`. End with the answer. If code should change, follow the shared handoff rule. The selected implementation playbook runs [Opening a PR](opening-a-pr.md).
